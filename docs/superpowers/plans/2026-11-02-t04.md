# T04 Prematch Features Implementation Plan

> **For agentic workers:** Use superpowers:executing-plans in the current session. User has chosen direct implementation and PR delivery.

**Goal:** 从已有球队赛果构造可追溯、无未来信息的赛前特征表，保存Parquet与缺失质量说明。
**Architecture:** read-only SQLite -> per-target eligibility -> scoped histories -> model/market/metadata separation -> exclusive hashed Parquet export.
**Tech Stack:** Existing Python/pandas/SQLAlchemy; optional pyarrow for Parquet.
**Spec:** ../specs/2026-11-02-t04-design.md

## Global Constraints
每场截点min(as_of,kickoff)，开球/可知/报价均严格小于截点；不训练、不改变现有预测；MODEL_FEATURE_COLUMNS不含market_或meta_；测试离线；临时环境；私有PR不合并。

## Review Focus
- 晚采集的旧比分与截点当天刚可知数据不得进入窗口。
- 主客倒置、跨来源重复、杯赛混入联赛均值；休息允许同来源跨赛事但必须披露。
- 窗口不足或空历史不得填0充当已观测均值；所有假设可知数据可查。
- 最近赔率不完整时只能取同一完整旧快照，不拼价格，不取hhad。
- 导出失败/文件已存在不得覆盖旧证据；空目标表仍可读出完整schema。
