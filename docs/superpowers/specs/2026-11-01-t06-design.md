# T06 批量赛前预测、报告与冻结存档

用户要求直接开发下一个功能。沿用现有 T06 任务单和对话约束，执行方式为当前聊天直接实现并提交私有 GitHub PR。

## 目标与约束

- 输入已入库的比赛 ID 列表/CSV，或北京时间开球自然日，真实调用已训练的 Dixon–Coles 模型。
- 模型仅使用历史球队比分，市场 SP 只作独立对照。新结果一律 P2/experimental_unadopted，BET 禁用。
- 常规90分钟含补时。拒绝模型截点晚于预测截点、未知球队、跨联赛/来源、已开赛和未知身份，不补猜概率。
- 显式历史回放必须带 --replay 与有时区的 --as-of，保留真实生成时间，不登记为事前冻结或未见验证。
- 保存完整原精度概率、比分矩阵、模型文件 SHA256、训练截点/数量/数据可知依据和当次完整 SP 快照。
- JSON 是冻结报告的来源；Markdown/CSV 只由该 JSON 生成，刷新赔率、回填比分不能改变旧报告。
- 输出目录不得覆盖；失败回滚本次数据库预测并清理本次创建的固定文件。多批次允许追加。
- 所有测试离线，不修改正式环境或已有用户预测。代码和实际验收报告交付私有 GitHub，自动采集仍按现有配置。

## 方案选择

继续封装已有 penaltyblog 1.13.1 模型及已有 CLI 是当前实现选择：避免重写模型、重复训练接口。网页与二串一属于后续任务。
冻结用独立批次 JSON + SHA256 清单及可读导出，先提供稳定的数据接口供未来网页读取；本次不引入网页框架或长期服务。

## 接口

- `zucai predict --date YYYY-MM-DD --model-file models/league.pkl [重复指定其他联赛模型] --out reports/batch-id`
- 替代日期：`--match-id jc:123` 可重复，或 `--matches matches.csv`（仅 match_id 必填）。选择方式互斥。
- `--as-of ISO8601 --replay` 仅用于明确标记的历史回放；当前预测不允许自行回填生成时间。
- `--market-weight` 默认0；显式>0另存实验混合行，不修改纯模型行/比分矩阵。报告保留纯模型为主行。
- `zucai report --batch reports/batch-id/forecast.json --out reports/export-id` 读取冻结 JSON 而非当前库。

冻结结构（schema_version=1）：batch_id、generated_utc、as_of_utc、mode(prematch/historical_replay)、
probability_type=P2、validation_status、bet_allowed=false、input、models、predictions。
models 包含 model_name/model_version(模型文件SHA256)、source、league、model_as_of_utc、training_games、
last_available_utc、availability_basis、assumed_training_share。
每场包含 match_id/source/league/jc_num/home/away/kickoff_utc/kickoff_beijing/status(predicted/excluded)/reason、
model_name/model_version/model_probabilities(h,d,a)/score_matrix/top_scores([{score,probability}])、
market(null或{prices(h,d,a),probabilities(h,d,a),snapshot_utc})、ev(null或h,d,a)、metadata、experimental_blend。
无效场次保留 ID、已有身份及排除原因，概率/矩阵不填值。

## 数据与时间

每个模型只匹配同来源同联赛。模型训练截点不得晚于预测 as_of，历史赛果可知时刻必须早于训练截点。
报价必须为单一时间完整 had 三项，早于开球且不晚于预测 as_of；不拼接单项报价，缺失时市场栏为空。
日期筛选明确是北京时间开球自然日，不将其称为竞彩编号日；具体竞彩编号另存。
数据库 predictions.created_utc 始终是真实计算完成时刻，并存 batch_id/mode/as_of_utc；旧行保持NULL未知。
导出后和事务提交前复查截止，跨过开球则整批回滚。历史回放不能记为赛前实录；比赛表保留最新赛程，
回放不是历史排期或取消可知性的证明。预测文件须提交私有仓库保存，现有feeds自动归档不包含它们。

## 验收

实际公开样例训练模型，输入比赛列表跑 predict/report，检查胜平负合计1、赔率空表不影响模型结果。
验证已开赛、未知球队/ID、未来模型截点、缺失或截止后报价、重跑不覆盖、后续改库不改变报告、DB失败不留假报告。
在临时目录恢复现有真实云端归档，用可用同联赛数据训练并预测尚未开赛场次；不足则如实排除。
完整测试/Ruff/独立审查通过后提交 PR，附真实命令、输入、输出与数据局限。
