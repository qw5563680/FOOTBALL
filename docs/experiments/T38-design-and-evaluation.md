## 数据与时间

新增 match_injuries，球队只沿既有 apif_fixture_index 连接，不能连接的记录保留 NULL 身份和审计。
历史季页始终 backfilled / available_utc=NULL；每日页只有 capture 严格早于条目开球才标 captured。
strict 特征中 backfilled 的有效可知时间为真实 captured_utc，必须严格早于 min(as_of,kickoff)，
同时保留原存储标记。训练 replay 明确假设历史名单在该场开球前已知，不声称恢复了当时的版本。
上一场首发仍须是已结束比赛，开球+3h 严格早于截点，且按相同时间口径选择阵容观察。

条目按内容变化保留版本，记录首次/末次捕获时间区间；内容未变只延长末次捕获时间。
完整名单快照与逐条拒绝明细不能每天膨胀 git CSV；压缩回执随 stats-raw Release 归档，CSV 只保留每页摘要与定位哈希。
特征仍按单次完整快照和真实捕获时刻选择，不把末次时间倒灌到首次，也不把不同抓取的玩家行拼成虚构名单。
空页/无本场名单/身份失败都保留 null；没有阵容仅使首发交集附加项缺失，不阻断已知伤停人数。

基准 main f7fa6c5 尚无 T34b 实现，因此选任务单允许的 T33 dc-sot-v1 宿主（fd 九联赛射正）。

附加列复述该子集的主候选/宿主/消融配对指标与可用人数差，不另行训练第三个候选。
共同截距、主场项、for/against、一个伤停系数和 rho 由折内似然拟合，不手设伤停扣分。
消融保持同一宿主，去掉该伤停项；消融与候选使用完全相同的完整输入训练样本和评价配对样本。
另保留原 dc-sot-v1 宿主在所有统计完整场次的覆盖率，六列为宿主/候选/消融各自 raw/calibrated。
仅复用训练折平局偏移，不增加校准算法；不读取赔率来训练、校准、选择窗口或填缺失。

## 冻结评价

沿 T33：2021-07 起训练，2024/25 按月选择 N=5/10，2025/26 按周评价（七月换季）。
窗口选择仅比较两个窗口均有真正候选输出的共同场次 raw LL，同分选小窗口；无共同样本则 N=5，标选参证据不足。
拟合只收 kickoff < label.available_utc < fit_cutoff 的标签；样本特征截点是自身开球，目标特征截点是目标开球。
这保留“周初拟合、逐场开球特征”的不对称，不能称为当时在线冻结结果。
训练技术统计用 T33 的开球+3h replay 假设，伤停训练名单用明确的历史名单假设。
目标表一 strict_capture_time 对统计与伤停均使用真实捕获时刻；表二 backfill_replay 假设最近归档伤停名单在开球前已知，
统计按 T33 开球+3h 假设回放。表二是反事实历史回放，不是严格历史实时验证或新前瞻证据。
两表独立选窗、拟合、六列评价、配对区间与子集分析；不得合并分母、跨表填空或用 replay 替换 strict。
旧历史季名单通常在评价期之后才抓到，因此 strict 共同样本可能为 0。这时六列空值、配对 n=0、区间 null，
结论为“证据不足，尚不能判断是否改善”，不得用第二张 replay 表给 strict 填空。

主指标 LL；辅以三分类求和 Brier、首项命中、10 桶校准、覆盖、比分 Brier。六组 raw 对 raw / calibrated 对 calibrated
配对差，UTC 周整块 bootstrap 2000 次、seed 3301、95% 区间。按联赛/赛季、冷启动、统计缺失、伤停缺失分组；
全目标与真实共同样本分别列出。无数据或拟合失败留空及原因，不用宿主概率冒充候选。
市场仅在全部拟合与选窗完成后从同场 jc 赛前完整 had 去水附加，不用 fd 收盘价替补。
不自动采用；即使改善也须另经前瞻积累和所有者决定。合成样本仅验证实现，不能作为精度证据。
