每臂先按截点判断可用，再以既有 `jc > fd > fdorg > apif` 从明确且身份有效的同场链接

可用后才替换。无链接、身份未核准或主客/开球冲突不能靠名称、比分或模型表现推断链接。

## 主要分母与指标

先导出完整目标清单与排除原因，再计算成绩。清单记录每个 `match_id + cutoff_utc` 的两臂
状态、所用参数、训练 ID/来源/有效时间/比分摘要哈希，以及最后一场赛果证据；同一目标只出现一次。
主要成绩分母为**两臂均成功给出合法概率且有相同可信标签的交集**。两臂独有可预测场次单列覆盖，
不得加入一侧主分母、以均匀概率填空、静默丢弃失败或择优挑选日期。

固定指标（整体、每个联赛及 ISO 周各一表，另外按是否增加上一场覆盖分组）：

1. **主指标：三分类 Log Loss**，`-mean(log(max(p_actual, 1e-15)))`，报告新、旧及新减旧。
2. 三类 Brier：`mean(sum((p-y)^2))`，不除以 3；报告同一配对分母的新、旧及差值。
3. 首项命中率：与记分板一致，使用 `fractional_credit_across_equal_maxima`；若最高概率有 k 项
   严格相等，真实结果在其中记 1/k，否则记 0；同一分母比较。
4. 覆盖率：目标总数、有效标签数、各臂成功数、共同成功数及所有排除原因。
5. 相同目标和同一截点下两队上一场结果是否在各臂实际训练 ID 集合中。
   “上一场”为该队在同一国内联赛、该截点前已开球且快照有可信完赛结果的最近一场；
   先以核准身份及同场链接确定实体，不以训练已包含行反向定义上一场。
   报告队次分母（每目标最多 2）、两队皆有、至少一队有、两队皆无、无可识别上一场、
   新增/减少/不变队次与比赛数，以及捕获距开球时长。旧 assumed 的“模型已包含”和
   “已证实实际入库”分列，不拿假设时间当真实时效。无法确定上一场或其可知时间的队次保留 unknown。

不读取 odds/closing_odds 作训练、选参、筛选或时效证据。P2 重产通道可按原 gate 独立读取
收盘对照，但其产物、分母和结论不得混入本主比较。

## 不确定性、采用标准与失败报告

- 固定按配对目标 ID 自助抽样 2,000 次，随机种子 `6301`，报告新减旧 LL、Brier、命中率的
  95% 百分位区间；同一 ID 的两臂始终一起抽取。同轮比赛共享训练更新，样本不独立，
  此区间只作描述，不能作为独立显著性证据。按联赛给出描述性结果，不按显著性筛联赛。
- 只有共同样本至少 500、LL 改善至少 0.005，且配对差值区间上界小于 0，才可称本窗口
  “确认了预测质量改善”。这只是本协议的声明门槛，不替代或改变 P2 gate。
- 时效改善须有逐场实际时间证据且新增上一场覆盖数大于 0；“更早”不自动推导“更准”。
  点估计很小、为零、负收益或区间跨零均按原数值报告，结论为“无法确认改善”。
- 新来源进入生产须通过身份、真实可知时间、冲突处理及回归检查。来源变化使 15 联赛旧 P2
  证据失效，先标 **P2 实验**；仅现行最近两完整季、样本数、等概率/收盘对照等完整 gate
  的新证据才能重新认证，不沿用旧 `p2_ready`。BET 始终禁用。
- 固定历史不变性检查截点为 `2026-11-14T00:00:00Z`。在两源均实际可用的配对实体上，
  比较旧/新所选训练比分、身份与时间；逐条列全部差异及其原因。模型若因新增独有场次或
  修复截点择源产生变化，逐场说明，不能把不同比较输入伪装成逐字节一致。
- 若缺新历史、权限、完整身份、来源版本或捕获证据，明确写“该部分未验收/证据不足”；
  不运行合成数据来补真实收益，不用无结果替代 0 收益，不借后续回填改变本固定分母。
