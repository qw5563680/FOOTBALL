# T33 第一轮：设计、冻结评估方案与实施计划

本文件和同目录 `T33-evaluation-protocol.json` **先于任何实验结果提交**。依据 main 的 T33 任务单及
所有者收敛要求，仅候选一与单项消融；不实现候选二、不调整正式模型或 params.json。
本轮是使用现有归档版本的历史回放，不称新的未见前瞻验证；采用决定留 T34。

## 方案与边界

现行 DC 从历史进球拟合球队攻防。候选一把强度解释量换成球队近期技术统计，以 DC 的赛果似然
学习统计量到进球强度的关系，**不把射正次数直接当进球、不把小数 xG 转成整数进球**。
与直接将 xG 当泊松整数标签相比，该方式保留真实90分钟比分标签并可学习射正的量纲转换；
与概率逻辑校准层相比，改动发生在比分分布的进球强度层，不使用第二轮候选。
这是实现者在任务单范围内选定的具体参数化，未经采用，名为 `dc-xg-v1` / `dc-sot-v1`。

同供应商、同联赛、同一规范球队的近 N 场已结束正式比赛，分别统计本队 for 与对手 against。
全模型：`log(lambda_h)=b0+home+b_for*log1p(home_for)+b_against*log1p(away_against)`；
`log(lambda_a)=b0+b_for*log1p(away_for)+b_against*log1p(home_against)`。
加 DC 的四个低比分修正，b0/home/b_for/b_against/rho 全部由训练折加权最大似然拟合。
消融仅删除 `b_against` 及对应输入；不同时删窗口、换数据源或改校准。
输入是近 N 场按90天半衰期加权的 xG 或射正；fd 与 apif 分开拟合、分表，不拼口径。
系数边界 [-5,5]、rho [-1,1] 只作数值约束；训练网格低比分修正须为正；新输入必要时约束 rho
以防负概率，并记录裁剪。拟合失败或特征不足回退基线并记录原因，不用临时手调参数挽救结果。

基线直接复用未经修改的 `DixonColes`，未知球队先验沿 T15；显式90天半衰期作为事先固定的
算法基线，**不是拿2026年选出的生产参数倒用到2024年**。所有模型使用同一训练折/截点和赛果标签。
保留基线原始/既有平局校准、候选原始/既有平局校准、消融原始/既有平局校准六列。
平局校准只调用 T15 的 `fit_draw_offset`，只用训练折；不增加特征校准器，不用赔率。
报告候选和消融的实际参数、训练场数、特征完整场数、模型版本及回退去向。

## 时间、版本和缺失

- 每个特征行截点 `min(as_of,kickoff)`；历史比赛必须 finished，历史开球+3h 严格早于该截点。
- captured 行还要求自身 available_utc 严格早于截点；不复用赛果时间代替技术统计时间。
- strict 默认模式排除 backfilled。显式 backfill_replay 仅以历史开球+3h 作**假设**可用时刻，
  每项传递 backfilled、原 capture 时刻、raw_sha256/version 和假设时刻；不能宣称当时实际可得。
- captured 更正按截点选当时可用版本；回填回放使用当前归档的最新非空版本，并注明可能含后来更正。
- 只用 period_basis=90、eligible_90；含加时/未知时段不用。对手视角按同一底层 match_id 去重。
  不合并未验证身份，不按相似名称绑定，不重新修改导入规则。
- 按最近 N 场选窗口，缺统计的比赛留在窗口，不能换成更早的完整场次。有效 n/N 逐项记录。
  任一所需统计缺失、窗口不足 N 或身份/时段冲突时该输入为 null，候选回退基线；0 是有效观测。
- 特征层同时提供 N=5/10 的均值与衰减均值、同主/客子集、xG/xGA、射门/射正/被射正、角球、
  红牌标记与 T13 赛程休息天数。对手 DC 参数只有截点前的模型可用时才记录；否则给出缺失原因。
  首轮只让白名单内 xG/射正进入强度方程，其余为研究字段，不暗中入模。阵容本轮不入模。

## 先冻结的切分、指标、分组

- 历史最早2021-07-01，2024-07-01以前用于初始训练。2024/25为选窗期，2025/26为最终历史评价期；
  半开区间，以 UTC 7月换季，日期见 JSON。不得用最终评价期决定窗口或删除失败候选。
- 每联赛/供应商先在选择期 monthly walk-forward 比较 N=5、10 的**原始候选**全目标 LL（含回退）；
  同分取5。没有任何可运行候选时记选择证据不足，默认5仅为回退诊断，不宣称选出了有效模型。
- 最终评价 weekly：周一/季初边界前1微秒训练。历史进球标签必须在训练截点前可用；
  每个训练样本的技术特征仍按该样本自身开球截点生成，不把周末/季末统计倒灌进去。
  每周可吸收更早评价周已结束的数据，窗口/公式不再变化，沿用 T15 累积训练。
- 主指标 LL；辅以三类求和 Brier、首项准确率、10桶校准、平局偏差、预测/实验覆盖率。
  概率真为0时 LL 为无穷，不靠裁剪掩盖；并列首项按并列项均匀分配命中贡献，说明是期望分数。
- 比分单独用0..9×0..9网格加“其他”一类的 Brier。复用现行网格归一化口径，其他概率为0；
  另列归一化前排除质量，不声称完整尾部校准。真实比分超网格仍计入其他标签，不能删除。
- 同比赛、同截点报告全目标（含明确回退）与共同成功实验子集。模型原始/校准、消融、等概率、
  同场同时 jc had 去水市场列完整保留；市场缺失为 null 并列 n。报价与训练数据物理分开，
  只在预测完成后附加，既不参与选窗，也不参与估计。历史 fd 收盘价不冒充同时点 jc 市场。
- 分组预设为联赛、赛季、基线未知球队/非未知球队、统计缺失/完整、欧战/国内；欧战无足够
  本轮统计时报告未覆盖及原因，不借国内技术口径伪造杯赛实验。
- 配对差异为候选减基线、消融减基线、候选减消融；LL/Brier 越小越好。按 UTC 周整块有放回
  抽样2000次、固定seed3301、95%百分位区间；同一比赛的两模型始终成对，跨联赛同周共用块。
  共同样本 n=0 或块不足时区间为空，不能把“全回退导致差值0”说成实验等效。
- 允许无改善；本轮任何结论都不修改 P2 门槛，不替换正式模型，不开放 BET/T28实验账户。

## 实施计划

技术栈：现有 Python / SQLite / numpy / scipy / pandas / penaltyblog，不加依赖。

1. `features/stats.py`：只读归档库建立版本索引，`StatsFeatures.build(target, as_of, mode, window)`
   返回值/证据/缺失原因；合成 fixtures 检查本场与未来泄漏、版本、空值、窗口、重复视角及回填标记。
2. `predict/experiments/intensity.py`：独立 DC 统计强度拟合、单项消融与原始/校准分布；测试参数确由
   拟合产生、无赔率输入、模型版本、非法时段/缺失回退和矩阵合法性。正式类不修改。
3. `predict/experiments/evaluate.py`、`metrics.py`、`command.py`：加载冻结 JSON，按 T15 边界逐折，
   先完成选择期再锁定 N，最终期只评价；只读数据库/hash前后核对，逐场JSONL及汇总/方案哈希输出。
   测试时间切分、同场配对、分组、bootstrap重现、市场隔离、输出禁止覆盖。
4. 从数据分支快照 restore_feeds + stats restore-rows，记录输入提交、库与行分片清单哈希。
   待审查者追加统计归档时再固定本次输入，不请求体育源站；跑 fd 九联赛与可用 apif 组。
   全量结果只进数据分支 experiments/t33/；main 的 reports/ 只 README + SHA256SUMS≤200KB。
5. 更新 README/ARCHITECTURE，运行 pytest/ruff；完整 diff 审查后开 draft PR，列全部指标与限制。

重点审查：同场技术统计泄漏；未来更正覆盖旧版本；部分窗口用零填缺；选窗期混入最终期；
回退结果冒充技术模型改进。测试必须逐项覆盖这五类问题。
