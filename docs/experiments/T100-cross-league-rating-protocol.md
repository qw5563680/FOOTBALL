## 评分与三分类概率

开球前用截点可知赛果重建评分。将符合条件的历史比赛按事件时间依次推进，在其开球事件冻结赛前预期，并在赛果可知事件更新评分。同一时刻先计算所有开球预期，再应用赛果更新，赛果更新按开球 UTC、比赛 ID 排序。每份快照只计算同场一份已核实的代表记录。

- 球队首次进入评分时，初值为该场赛事里已经有评分的球队中最低 `ceil(n/4)` 个评分的算术平均；赛事池为空时取 1500。同一球队跨联赛、跨赛季保留原评分。用该时刻之前已有赛果的球队确定赛事成员，同刻首次出现的球队不进入彼此的初值样本。同刻有多个首场时以比赛 ID 排序确定首次赛事。
- 定义 `z = R主 − R客 + H`。归档未提供统一的中立场标记，固定给记录中的主队 `H`，将此作为模型限制披露。令 `L(x)=1/(1+exp(-x))`。有序三分类 `p客 = L((-D−z)/S)`，`p主 = L((z−D)/S)`，`p平 = 1−p主−p客`。`D>0` 给平局一个区间，`S>0` 控制斜率。参数只对赛果按下表拟合。
- 赛前主队预期 `E = p主 + 0.5 × p平`。赛果 `y` 按主胜、平、客胜取 `1, 0.5, 0`。主队加 `K × (1+ln(max(1, |主球−客球|))) × (y−E)`，客队减相同数。预期固定在该场开球前，晚到比分不得改变其他比赛当时的预期。需要出预测的目标如果一队没有评分，留空并记录球队及原因，初始值只用于历史评分更新。

| 候选参数 | 固定网格 |
| --- | --- |
| 更新幅度 K | 16、24、32 |
| 主场 H | 35、65、95 |
| 有序模型斜率尺度 S | 150、200 |
| 平局区间比例 r（D = r × S） | 0.50、0.60、0.70 |

54 个组合按相同的赛前截点逐折预测，选参段所有组合在共同有效目标上比较三分类 Log Loss。目标是正式模型所覆盖的赛事中有有效标签的比赛，按正式回放的赛程折和赛果代表选择；组合共享同一批评分输入和目标。取最低 Log Loss，数值相同时按 `(K,H,S,r)` 升序取第一项。没有共同有效比赛或概率有非有限值时暂停并记录原因。读取验证段标签前，保存完整网格、选定参数、取到最小或最大值的维度、比赛分母、切点及产出哈希。边界只作记录，候选表保持固定。

## 比较与记录

- 两模型按同一比赛 ID、同一周折截点配对。先记录全部目标、无有效标签、正式模型无预测、评分模型无预测、跨切分周折等排除项，再在同一批样本上报告两列结果及其差值。主指标为 `−ln(真实类别概率)`，零概率记无限损失；次指标为三类平方误差之和 Brier 和最高概率命中率，并列的命中按 `1/k` 计。校准按三类分别报告十个等宽概率区间的均值、实际频率、样本数及加权绝对差。覆盖率以正式已评分目标为分母，共同合格场次为分子。
- 回溯报告同时给出 Log Loss 差的 95% 描述性区间，按开球 UTC 周整块自助抽样 2,000 次，种子 3301。回溯门槛按点估计判定。欧国联的固定参数口径在逐联赛表单列。
- 所有联赛合并为一组做主比较和前瞻采用判定。另报告各联赛和正式模型任一方使用 `weakest_quartile_half_shrinkage` 的子样本，均为描述性结果。没有正式模型的赛事只统计两个队都有评分的场数。成绩单的「各半平均」仅在同场共同样本上按类做两组概率的算术平均，标明「对照，不是一条实验线」。它没有冻结预测行。前瞻采用规则与周整块自助区间沿用 `t34a-adoption-v1`，达标提交所有者决定。
- 首次回溯及任何失败或重跑，在 PR 记录协议及代码提交、Claude 审查链接、协议 SHA-256、起止 UTC、输入和输出 SHA-256、原因、逐场分母及归档位置。参数与分组在读取验证段成绩后保持冻结。确需更改时先停，由所有者决定。逐场文件按任务规则走数据分支或 Release，代码分支的 `reports/` 只保存 README 和 SHA256 清单。

## 失败标准

出现任何一条就关掉这条线，把实验位让出来：

1. 回溯阶段：验证段上，评分模型的 Log Loss 比正式模型同场高出 0.015 以上。直接不上线，不占实验位。
2. 前瞻满 300 场共同样本：Log Loss 差（评分模型减正式模型）的 95% 区间下界大于 0，也就是明确更差。
3. 前瞻满 600 场共同样本仍未达到采用门槛，并且「各占一半的平均」也没有胜过正式模型（95% 区间上界不为负）。
4. 任何一次发现用到了市场信息或截点之后的数据：立即停用并复盘。
