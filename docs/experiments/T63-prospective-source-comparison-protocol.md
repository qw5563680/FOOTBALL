## 对象、训练和测试期

- 主比较只包括当前真正并行冻结新旧版本的七联赛：英超、西甲、意甲、德甲、法甲、葡超、巴甲。
  八个直接切换的实验联赛只报告覆盖与资料时效，不在缺旧臂时伪造配对成绩。
- 旧臂为已批准的原 `fd,jc` 方法定义，新臂为同一数值方法的扩展赛果来源候选。
  固定各自 `model_definition_id`，记录每次模型 SHA、参数文件、原始资料清单与代码提交。
  定义改变则停止该配对组并单列原因，不能拼接多个定义挑好结果。
- 训练期为每次正式冻结截点之前的全部合资格历史；按真实可知时间、身份核验时间与同场关系
  选行。每次训练截止严格早于目标开球。测试是未来连续时间段，不随机拆分、不回填测试输入。
- `t0` 定为本协议获批且 T63 上线后，第一个成功产生可验证新旧两版发布证据的正常每日批次的
  训练截点，保存 UTC 与北京时间。测试目标为开球在 `[t0, t0 + 84天)` 的全部七联赛竞彩比赛。
  `t0` 不根据已知比赛结果选择；84 天到期即封窗，样本不足也不延长。只有完整结束后作主结论。
- 使用现行既定选参协议，不因测试期成绩改参数、联赛或来源优先级。赔率、收盘价与技术统计
  不进入训练、校准、先验、选参或本次比较；市场参考继续独立。

## 逐场配对与缺失

以竞彩比赛 ID、双方身份、90 分钟比赛口径配对。每场先列所有可信赛前批次，按同一原始数据
清单 SHA、训练截止、预测截止以及两版实际发布证明选择最后一个共同有效批次。
两版生成、各自真实发布时间都必须严格早于开球；后附候选不能继承旧版发布时间。
不把开球后重算、回放批次或只有本地装配时间的候选作为赛前预测。

主分母为新旧均给出合法三分类概率且有同一可信 90 分钟标签的交集。两版概率均用各自真正
冻结文件，不补算、不抄赔率、不用另一臂填空。每场保留：两版状态、固定原 ID、各自生成/发布
时刻、共享截止、哈希、配对或排除原因。候选训练失败、缺发布时间、无标签、身份冲突、
延期/取消等分别计数；单边可预测仍计入覆盖，不静默删除。

标签在窗口结束后第 7 天冻结，使用当时已核实的 90 分钟含补时赛果；加时和点球不计。
争议赛果、判罚与场上结果尚未由所有者决定时保留争议并排除共同评分，不自动改旧账。
之后的修正另发版本，不重写已封存结果。

## 时效证据

冻结时保留两臂真正使用的训练 ID、来源、比分版本、有效可知时间、身份/关系证据及清单哈希。
当前训练摘要若不足以复核这些内容，须先在后续任务补齐并获审，不能从后来的数据库猜回旧输入。

每个目标的每支球队，查该国内联赛中截止前最近一场已结束、可确认身份的比赛实体，
先定义实体再检查其是否在两臂训练集合；不以训练集合反向选择“上一场”。
队次最多为目标数乘 2。分别列新旧：两队皆有/一队有/皆无/无法核实；新增、减少、不变队次；
实际首次观察距开球的时长。旧 FD assumed 时间和已证明实际入库分列，不能混称实时资料。
按联赛及 ISO 周分列，区分来源正常运行和采集故障周，不删去故障周美化成绩。

## 指标、分母和采用门槛

在同一共同分母上固定报告旧、新、新减旧三列：

1. 主指标三分类 Log Loss，使用自然对数及固定下界 `1e-15`。
2. 三类求和 Brier（不除以 3）。
3. 首项命中率使用记分板 `fractional_credit_across_equal_maxima` 平手规则。
4. 覆盖率：全目标、可信标签、两臂各自成功、共同成功及逐原因排除数；另列时效队次分母。

整体和逐联赛同时报告。固定按北京时间开球所在自然周为块，对配对记录一起重抽样
2,000 次，种子 `6302`，给差值 95% 百分位区间；不足 8 个有效周不作区间支持的改善判断。
周之间仍可能相关，区间只作描述，不声称严格独立显著性。

只有共同样本至少 500、覆盖至少 8 个自然周、Log Loss 改善至少 0.005，且差值区间上界小于 0，
才称“此窗口支持改善”。时效改善另需真实逐场证据及新增队次大于 0；更早不等于更准。
不足、无改善、负改善或区间跨 0 均如实写“无法确认改善”，不延长窗口或改阈值追结果。
该门槛仅用于研究结论，不批准候选转正；是否采用仍由所有者按转正规程决定，BET 保持禁用。
