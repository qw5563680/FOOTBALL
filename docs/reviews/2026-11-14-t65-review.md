1. **真实目录仍被拒收（第一轮，必须修）。** 五个赛事各有一个年份出现两条赛季记录：397 安哥拉 2018、

   任务单原先写失败原因只有 id 271 一条，是审查者核对不全，那一条的日期错误掩盖了这五组。
   处理：所有者合并 PR #136 确认按单赛事隔离。`4a7ea57` 实现：冲突赛季标为 `conflict`，保留全部原始记录
   与原件指针，回填规划排除；结构性错误仍整份拒收。
2. **候选路由的联赛名是英文目录名且有重名（第一轮，必须修）。** `FA Cup` 两个、`Super Cup` 三个。
   处理：`f281cfe` 改为唯一的中文名，登记表校验拒绝同一提供方导入路由重名。一对一开售的赛事用竞彩官方简称；
   官方只有泛称的 7 个（世预赛四个分区、国际友谊赛、国际足联系列赛、国际足联洲际杯）用细分的项目名，
   它们与竞彩的「世预赛」「国际赛」不能靠同名对上，留给 T68。
3. **新核准路由不应同时开每日采集（第二轮，必须修，属审查者补课）。** 第一轮审查写了「可以改为已核准并开启下载」，
   T65 与 T61 任务单也要求每日采集同步覆盖，实现方照做无误；审查者当时没有核对每日采集路径。
   补查发现：62 个新赛事没有任何球队绑定，同名联赛内与竞彩场次相差三小时以内的接口比赛会被判疑似重复而不入库；
   过去 12 个月竞彩在这些赛事里开售 1,083 场（21.8%）；apif 采集状态会由 `complete` 变为几乎每天 `partial`；
   新赛事的拒收行还会让既有联赛的候选别名整份跳过。
   处理：所有者合并 PR #136 确认「先只开历史回填」。`4a7ea57` 把 62 个路由改为 `daily=false`、`backfill=true`，
   日期导入与候选生成共用每日范围。每日采集由 T68 在球队绑定完成后逐个赛事开启。
4. **英冠 40、法乙 62、巴甲 71 留在候选（第一轮，建议修）。** 属 T63 范围。已采纳。
