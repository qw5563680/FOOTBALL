# T55 复盘按发布时间选版本审查

- 对象：PR #115（`codex/T55-scoreboard-publication-time`，head 2710059，base c1ace6f，+1490/−59，37 文件，草稿）。
- 背景：独立复核（ChatGPT）问题 3——复盘选版本不比较发布时间；附带 T52 两条遗留小修。
- 审查方式：完整 diff 阅读；独立环境复跑 ruff 与全量 pytest；自建数据分支完整历史克隆（275 个提交，固定在

  日报并逐字段比对；另构造 3 个反例（单批次证据缺失、无 git 证据、模拟推送后确认）。

## 验证结果

- 发布时间推导：审查者自行 `git log --diff-filter=A` 得到 198 个冻结文件的首次加入提交，与
  `publication_times()` 逐条一致。「生成早于开球、发布不早于开球」全归档恰 4 条，即 run 42380973719 的
  4 场德甲（生成 14:28:57、提交 14:34:18、开球 14:30 UTC）。
- 验收 1：4 场改选 `42358846882-1-2026-11-07`；模型总样本 96、对数损失、Brier 与 main 完全相同
  （正式概率不变）；xG 德甲共同样本 5→9（合计 31→35）。
- 验收 2：记分板分别计数 `published_after_kickoff` 4、`publication_unknown` 0；把一个批次标为未确认后
  `publication_unknown` 计 6。
- 验收 3：`scored.jsonl` 原字节为前缀、仅追加 4 行；`active_keys` 仅 4 处变化；A–E 与 F 账户汇总与 main
  相同；两本账本字节不变。
- 验收 4：重放只改写记分板自身三个输出；ruff 通过；全量 pytest 仅剩与 main 相同的 16 例环境漂移失败
  （PR 改动了这两个测试文件，以远端 CI success 为准）。
- 新批次回执：真实归档副本上模拟「推送成功 → `forecast_publication` → `sfc_reports --confirm-publication`」，
  3 个预测日的正式/实验/复式回执全部写入，`verify_forecasts` 通过。
- T52 附项：真实库 5 对并存的 jc↔apif 欧国联比赛 `_same_national_counterpart` 全为真；日报提示不再报映射计数。

## 分级结论（已发 PR review）

- 必须修 1：`publication_view` 在发现任一不合格旧注单时从零重放整本账并向冻结账本追加重放记录。
  真实数据上零不合格时直接比较，从零重放与真实账本差异很大（1.05/A 38→29 注、全部变成事后回放、
  F 账户 123 条中 81 条不同）；只把一个旧批次标成发布未知即触发：`excluded_tickets` 33，
  `ledger.jsonl` 1959→2153 行。真实数据当前不触发，但与任务单「不回写旧账本文件」不符，且会让前瞻证据
  门槛失真。建议只剔除不合格注单并计数，不追加重放记录。
- 必须修 2：日报对 `active_keys` 的比较恒不相等（包含待结记录的键），每次都不带 `forecast_rows` 重算
  概率汇总：真实 11-12 日报少了「欧国联 / 欧战：前瞻样本 0 / 200」两行，默认实力分层在内存中被清空。
  `tests/test_daily_digest.py` 的主夹具把新逻辑打桩成恒等，回归未被发现。
- 建议修 3：git 证据整体读不到时只记 warning、退出码 0，输出清零的记分板与缩水的日报；建议让 job 失败。
- 建议修 4：历史证据每次从 git 历史现推，数据分支改写历史或浅检出会让旧记录全部变未知；建议一次性落盘。
- 建议修 5：PR 描述未提改选后市场基准指标的小幅变化（德甲市场对数损失 0.6004→0.6003）。
- 仅说明：与 #114 在 `digest_parlay.py` 冲突；回执时间取确认时刻、口径偏保守；合并后首个真实预测 run 需
  线上验收（清单出现 `publication_required` 与回执，记分板/日报正常使用新批次）。
