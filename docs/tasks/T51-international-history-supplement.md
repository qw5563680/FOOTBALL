# T51 带校验的国家队历史资料补充

用户决定：只做带校验的历史资料补充，保留现有可靠赛果，不用新库覆盖旧记录。

## 范围

- 沿用 international_results 已核验样本：2025-06-05 西班牙—法国赛前双方各10场正式比赛，20个球队视角、19场不同比赛。
- 对固定源码、原始 CSV、球队映射和正式归档副本校验 SHA256、比赛身份、主客方向、UTC 时间及90分钟比分。
- 16场既有欧国联赛果只读保留。单独补存3场欧洲杯历史参考记录（uefa:2036206、2036209、2036211），使用明确的 UEFA 身份，不编造 API-Football 比赛编号。
- 加时比分与90分钟比分分开，来源原值和独立核验依据同时保留；冲突或身份不明停止整批写入。
- 可离线重放、重复新增0条、归档复制后校验读取；保留真实取回时间，不虚构当时已知时间。
- 独立分支、草稿PR；全量验收在独立资料分支，不触碰 data/football-feeds。

## 不做

不全库导入、不模糊匹配、不自动覆盖或补全既有行；不写生产库、预测、日报或账本；不调整模型、参数、BET 或配额；不新增自动采集/任务、不使用正式密钥、不合并PR。
这3条是历史参考补充，尚不进入正式训练或回测。源库不能补射正、xG、角球等39项技术统计。

## 验收

1. 固定19场中只新增3场，已有16场内容完全不变；西班牙—荷兰保留90分钟2:2，来源含加时3:3仅作差异说明。
2. 三场比赛逐一核对球队、赛事、开球时刻、中立场和常规比分。葡萄牙—法国0:0不记成点球3:5。
3. 同一输入重复运行新增0，既有输出逐字节不变；数据打包恢复后内容和哈希一致。
4. 哈希篡改、缺少原件、原始重复身份、未知球队ID、比分/时区/比赛身份冲突等失败时不产生补充结果。
5. 全量pytest、ruff check、ruff format --check通过，记录实际版本、数据版本、原件哈希和限制。
