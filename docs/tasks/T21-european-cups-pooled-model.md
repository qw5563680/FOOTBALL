# T21 · 欧战联合模型：跨联赛 Dixon-Coles、评估与每日预测

## 背景
现有 `DixonColes` 一个联赛一个模型，`fit` 拒绝混合联赛历史。欧战是跨联赛对阵，拜仁对阿森纳既不能用德甲模型也不能用
英超模型。T20 之后数据分支有欧冠 2023 起、欧罗巴 / 欧协联 2022 起的历史，以及参赛球队所在国内联赛的六赛季历史。
欧战比赛本身把各国联赛连成一张图：把国内联赛比赛和欧战比赛放进**同一个** Dixon-Coles 里联合拟合，球队攻防参数自然落到
同一把尺子上，不需要人为设定「联赛系数」。本任务实现这个联合模型，用欧战历史做 walk-forward 评估，并接入每日预测。
本任务单在 T20 验收后定稿：参赛球队对齐率、可用赛季数会影响评估窗口与门槛数值。

## 目标
1. 一个「欧战联合模型」：训练集 = 当季及历史上有球队参加三项欧战的所有已核验国内联赛比赛 + 三项欧战比赛 + jc 欧战赛果；
   预测对象 = 竞彩在售的欧冠 / 欧罗巴 / 欧协联场次。
2. 用 T15 同一套方法评估：按赛季 walk-forward，模型 / 等概率 / 市场三列；市场列用 jc 赛前最后一次 had 快照去水
   （欧战没有 football-data 收盘价）。
3. 半衰期按 T15 方式选参并写入 `params.json`；P2 门槛沿用，但证据按「欧战」整体计算。
4. T17 每日训练加入这个模型，T06 报告对三项欧战给出概率、比分前五与 P2 标签；T19 记分板按赛事分别计分。

## 范围
1. **模型**（`src/zucai/predict/dixon_coles.py` 或新模块 `pooled.py`）：
   - 新增 `DixonColes(pooled=True)`（或子类）：允许多联赛历史；`league` 元数据记为 `欧战`，`training_leagues` 记录实际
     参与联赛与各自场数；球队身份用规范名（T20 对齐后的 jc 中文名），未对齐的 `fdorg:team:*` / `apif:team:*` 作为独立球队参与拟合；
   - 主场优势：欧战主场优势通常弱于国内联赛，**先只用一个共同主场参数**并在评估里披露；若评估显示欧战子集校准明显偏主队，
     再在 T21a 加「赛事类型主场偏移」；
   - 未知球队先验沿用 T15 规则（训练集最弱四分位收缩）；
   - `predict_with_metadata` 增加 `pooled: true`、`training_leagues`、双方球队各自来源联赛。
2. **训练语料选择**（`src/zucai/predict/command.py`）：新增 `--pool-leagues` 或由 `params.json` 条目的
   `leagues` 字段驱动：`leagues: ["欧冠","欧罗巴","欧协联"]` 为预测目标，`training_leagues` 为语料范围
   （默认：三项欧战 + 15 个已核验联赛中有球队参赛的联赛），`sources: ["jc","fd","fdorg","apif"]`。
3. **评估与选参**（`src/zucai/predict/backtest.py`、`tuning.py`）：
   - `evaluate` 支持「评估目标联赛集合 ≠ 训练联赛集合」：训练用全部语料，只对目标联赛场次评分；
   - 赛季按 7 月换季；评估季 2324、2425、2526（欧冠）与 2223–2425（欧罗巴 / 欧协联），jc 赛前 had 为市场列；
   - `tune` 对 `欧战` 条目做 rolling-origin 选半衰期，窗口与 T15 一致；
   - P2 门槛：三项欧战合并为一个证据组 `欧战`，最近两完整季合计 n ≥ 500、模型 LL 比等概率低 ≥ 0.05、
     同场模型 LL 不比 jc 市场列差超过 0.05（收盘价条件改为 jc 赛前市场，配对 n ≥ 300）；三项赛事共用该标签。
4. **每日预测**（`src/zucai/cloud_predict.py`、`src/zucai/report/batch.py`）：`params.json` 增加 `欧战` 条目后，
   T17 自动训练联合模型；模型注册到 `(jc, 欧冠)`、`(jc, 欧罗巴)`、`(jc, 欧协联)` 三个键；摘要的训练行显示 `欧战`
   与其 `training_leagues` 场数；T19 记分板与虚拟账户按赛事名分别统计（无需改 T19 代码，联赛名即赛事名）。
5. **测试**：混合联赛拟合与单联赛拟合在只有一个联赛时结果一致；目标联赛评分集与训练集分离；市场列缺失时为 null；
   `欧战` 条目的 `model_readiness`（来源集合、训练联赛集合、证据季）；三项赛事注册键；未对齐球队作为独立身份参与拟合。
6. **报告** `reports/<日期>-t21-cups-model/README.md`（≤ 200 KB）：三项赛事逐季三列指标、推荐半衰期、主场优势校准、
   P2 判定；全量 JSON 放工作目录。
7. **文档**：README 评估一节补「欧战联合模型」；`docs/ARCHITECTURE.md` 模型一节补 pooled 模式与 `params.json` 新字段。

## 不做
- 不做联赛系数或 Elo 类外部评级；不引入新依赖。
- 不改 15 个国内联赛的单联赛模型与其 P2 证据。
- 不改采集、去重、身份规则（T20 负责）。
- 不启用 BET；报告不出现购买建议。

## 验收标准
- 真实数据评估（T20 回填后的数据分支快照）：PR 描述给出三项赛事最近两完整季的三列指标、推荐半衰期、`欧战` P2 判定及原因。
- 评估 n：欧冠 ≥ 300、欧罗巴 ≥ 300、欧协联 ≥ 200（按 T20 实际对齐率调整，PR 写明）。
- 真实触发一次 `operation=predict`：摘要出现 `欧战` 训练行，当日在售欧战场次给出概率与比分前五。
- `pytest -q` 全绿、ruff 通过；`reports/` 只提交 README 与 SHA256SUMS。
