# T72 球队＋市场融合实验线：同截点冻结，三方同批比成绩

来源：所有者 2026-11-17 批准。规则见 `AGENTS.md`「市场信息的使用」。依赖 T71（市场参考的计算与出处）。
分支 `<实现方前缀>/T72-team-market-blend`，PR 标题以 `T72:` 开头。

## 假设

把市场参考概率与球队模型概率按一个权重合并，得到的概率比球队模型更接近实际结果。
它是否比直接看市场更好，是另一个问题，本单单独回答，不预设答案。

## 现状

- 线上已完赛、赛前冻结的预测，同一批 119 场配对：竞彩赔率去水概率的 Log Loss 0.9165，球队模型 0.9722，均匀分布 1.0986。
- 冻结预测里已有 `experimental_blend` 位置和 `experimental_blend_market_weight` 等报表列，目前没有内容。实现前先读既有代码，接着用。
- 发单时刻的竞彩报价快照从 2026-11-01 起才有；2021 至 2026 年的多家公司报价是收盘价。

## 范围

1. **融合方法（事前写定）。** 输入只有两样：已冻结的球队模型胜平负概率，以及 T71 的市场参考概率。
   按对数线性合并：各项取「球队模型概率的 (1−w) 次方 × 市场参考概率的 w 次方」，再归一。初版只有一个参数 w，取值 0 到 1。
   模型名 `team-market-blend-v1`，标注「球队＋市场（实验）」。
2. **权重怎么定。**
   - 起始权重由回溯实验给出：在球队模型已有逐期回测预测、且有收盘报价的历史比赛上，按时间切分为训练、验证、留出三段；
     只在训练段选 w，验证段看一次，留出段只在权重写定后算一次并原样报告。
     这份回溯用收盘价代替发单时报价，会高估市场，报告里必须写明，结论只标「回溯」。
   - 起始权重连同切分方式、样本量、三段成绩写进仓库的协议文件，提交之后才开始前瞻计分。
   - 之后只在事先写明的检查点（前瞻共同样本每满 200 场）用前瞻冻结数据重估一次；重估得到的权重只对之后的批次生效，记为新版本。
3. **冻结。** 每批预测里，球队模型有结果、且 T71 取到了不晚于截点的合格快照的比赛，才生成融合概率，写入该场的 `experimental_blend`，
   同时记下权重、方法版本、所用市场快照的标识与采集时间。任何一边缺失就标「未生成」并写原因，不用市场概率顶替。
   预测发出之后取得的报价（含收盘价）不参与融合，只用于赛后对照。已冻结的批次不因后来补采而改写。
4. **三方同批比成绩。** 记分板新增一节，三栏都按同一个截点冻结、用之后踢完的比赛检验：
   - 覆盖：每栏在已发布比赛里各漏了多少场，分别因为什么。
   - 共同样本（三栏都有结果的比赛）上分别列出场数、Log Loss、Brier、首选命中率。
   - 两组按比赛编号配对的差值及 95% 区间：融合减球队模型；融合减市场参考。
   - 结论用语事先写定：融合减球队模型的区间上界小于 0，才写「市场信息帮到了球队模型」；
     融合减市场参考的区间上界小于 0，才写「融合比直接看市场有额外好处」；否则写「尚无证据」。
   - 收盘价对照单列，标明「赛后对照」，不与上面的同截点比较混在一起。
5. **日报。** T71 的第三栏「球队＋市场（实验）」填入融合概率；融合使首选方向发生变化的比赛加标记，并写出变化了多少。
6. **成绩单独记。** 融合实验线不进入虚拟账户与纸面串关，`paper_eligible` 为否；这两者继续按球队模型原有的资格运行。不适用转正规程。

## 验证与样本

- 回溯部分：报告三段各自的场数与成绩；留出段只算一次。
- 前瞻部分：从本单合并后的第一批冻结预测起算，不回填。共同样本不足 200 场时只报数字，不下结论。

## 失败标准（事前写明）

- 前瞻共同样本满 300 场后：融合减球队模型的区间上界不小于 0，判定「市场信息没有帮到球队模型」，关停这条线。
- 同一时点：融合减市场参考的区间下界大于 0（融合明显不如市场），关停。
- 融合与市场参考无显著差别时，如实标注「与市场参考相当，无额外好处」，是否保留由所有者决定。

## 成本

- 不新增接口请求，不新增数据来源；新增一份协议文件、预测记录里的一个既有位置、记分板一节、日报一栏。

## 验收

1. 球队模型不变：融合开与关两种情况下，同一归档副本、固定时刻重放得到的训练行数、模型内容、球队模型概率与比分矩阵逐项相同。
2. 融合概率三项合计为 1；w 取 0 时等于球队模型，取 1 时等于市场参考；任一边缺失时不生成。
3. 采集时间晚于截点的快照、收盘价、赛果不会进入融合；针对这三种情况各有一条测试。
4. 记分板的两组配对差值能由审查者用独立脚本从冻结文件复算出来。
5. 虚拟账户与纸面串关的账本在本单合并前后逐字节相同。
6. 全量 `pytest -q`、`ruff check src tests examples`、`ruff format --check src tests` 通过；README 与 `docs/ARCHITECTURE.md` 同步；
   `reports/` 新增不超过 200 KB。

## 不做

- 不改球队模型，不让融合结果回流到任何模型的训练、校准或选参。
- 不加入亚洲让球、大小球、必发、凯利或走势类特征；这些要等真实数据接通并另开任务单。
- 不给下注建议，不计算真实收益；BET 保持禁用。
- 不替换正式预测，不申请转正。
