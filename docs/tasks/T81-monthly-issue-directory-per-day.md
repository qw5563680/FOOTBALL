# T81 「每日报告」页的目录：一天一行

来源：所有者 2026-11-25 看到「每日报告 2026-11」页面变乱后要求查明并修；
`docs/reviews/2026-11-25-codex-217-224-audit.md` 第 2 条。

## 问题

#220 把 `src/zucai/digest_notify.py` 里 `monthly_issue_body` 的目录，从「一天一行、链接到当天评论」
改成了「每个运行版本一行、链接到数据分支的归档文件」。一天三班再加补跑，11 月的目录到 11-25 已有 77 行，
每行形如 `2026-11-25 · 45479530916-1`。所有者看不懂这些编号，也翻不到想看的那一天。

## 范围

1. 目录恢复为每个北京日一行，最新在前：`- [2026-11-25](链接)`。
2. 链接指向当天的机器人评论；当天没有评论（或评论列表读不到）时，指向当天最新一版的归档文件。
3. 同一天再跑一班、或者补发，目录行数不变。历史版本不在目录里逐条列出，需要时到数据分支 `daily/<日期>/` 查。
4. 「最新日报」仍嵌在目录下面；放不下时沿用 T80 的缩短规则。
5. 自动目录标记之间的内容每次都是整体重写，所以正式运行第一次生效时，现有的 77 行会自动换成一天一行，
   不需要人工清理。
6. 同步 `docs/ARCHITECTURE.md` 的日报通知一节。

## 不做

- 不删除、不改写任何已发的评论和归档文件。
- 不改每月轮换、置顶和关闭上月的逻辑。
- 不改评论本身的发布规则（那是 T80）。

## 验收标准

1. 离线测试：一个月 25 天、每天 3 个版本 → 目录正好 25 行，最新在前，每行链接到当天评论。
2. 离线测试：某天没有评论 → 该行链接到当天最新归档版本。
3. 离线测试：同一天再跑一版 → 目录行数不变，「最新日报」换成新版。
4. 离线测试：评论列表读不到（`comments is None`）→ 沿用正文里已有的一天一行链接，不丢天数。
5. 现有 `digest_notify` 测试全绿（目录格式的断言按新格式更新）。
6. 合并后验收（Claude）：下一班正式运行后，「每日报告」页的目录是一天一行，行数等于当月已有日报的天数。
