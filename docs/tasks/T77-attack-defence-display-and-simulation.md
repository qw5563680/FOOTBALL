# T77 进攻/防守强度展示与一万次模拟（多场合起来的概率）

来源：`docs/proposals/2026-11-19-attack-defence-simulation.md`；所有者 2026-11-19 决定「先做第四点」。
实现与审查分工按所有者当前安排（Claude 实现并开 PR，DeepSeek 审查与合并）。PR 标题以 `T77:` 开头。

## 范围

1. **展示进攻/防守强度。** 球队模型本来就为每支球队估了进攻值和防守值。每条冻结预测新增 `team_strengths`：
   主客队的进攻指数、防守指数（100 为该模型全部已拟合球队的平均，越高越强）、这场比赛的预期进球、是否用了默认实力。
   日报在预测表下方列一张小表并用一句话说明读法。
2. **模拟引擎。** `zucai.simulate`：从冻结的比分矩阵或胜平负概率抽样 10,000 次；种子由冻结输入导出，结果可重现；保留精确算法对账。
3. **胜负彩「中几场」。** 任九一节加一行：九场全中、错 1 场、错 2 场、错 3 场及以上的概率；14 场一节同样加一行（只算有预测的场次）。

允许改动：`src/zucai/predict/dixon_coles.py`（只新增只读方法）、`src/zucai/report/batch.py`、`src/zucai/simulate.py`、
`src/zucai/report/sfc.py`、`src/zucai/sfc_digest.py`、`src/zucai/digest_views.py`、`tests/`、`docs/`。

## 验收

1. 一致性：同一场比赛，10,000 次抽样得到的胜平负与公式结果各项相差不超过 1.5 个百分点；固定种子重复运行逐字相同。
2. 「中几场」的抽样分布与精确分布逐档相差不超过 1.5 个百分点，各档之和为 1。
3. 预期进球等于模型对该场的进球率（差不超过 1e-9）；进攻指数的排序与模型参数一致；指数的几何平均为 100。
4. 展示不改变预测：调用前后比分矩阵逐元素相同；`team_strengths` 取不到时为 `null`，预测照常冻结。
5. 旧批次（没有 `team_strengths`）的日报字节不变；既有预测、冻结、结算、账本文件逐项不变。
6. 不读取赔率、收盘价或任何市场信息；模拟不回流到模型。
7. 全量 `pytest -q`、`ruff check src tests`、`ruff format --check src tests` 通过；测试不联网。

## 不做

- 不用模拟替代单场胜平负的公式结果（模拟只会多一点抽样噪声）。
- 晋级概率（两回合淘汰赛、加时、点球、联赛阶段排名）：需要先给赛果补「加时比分、点球比分或晋级方」字段，并经审查者在 Actions 探测拿到真实样本，另行立单。
- 实时滚球：理由见提案第 8 节。
- 不改模型的拟合、参数、冻结与成绩；不占实验线名额。
