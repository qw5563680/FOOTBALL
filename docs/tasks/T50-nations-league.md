# T50 欧国联国家队比赛进入正式赛程、训练、14 场与任九

第 26163 期的 14 个原始场次都属于男子欧国联。国家队赛程来自 API-Football 的赛事 5。用历届常规时间比分单独训练国家队 Dixon–Coles 模型。主客队、日期和比赛身份一致才向仍在售的期次提供冻结预测，保留已有的停售与开球检查。除当日和次日的竞彩外，只给在售期次中已匹配的欧国联场次延长预测窗口。

首版按两年半衰期衰减，未调参，未获 P2 可用评级。历史整季回填沿用项目的已知时间假设，取开球后 6 小时，原始抓取时间另存。评估保留原规则与假设标记。原始赛程的主客顺序用于估计主场效应，中立场地尚未单独建模。技术指标与赔率不作为这一版的训练输入。旧预测继续使用生成时的模型与数据。
