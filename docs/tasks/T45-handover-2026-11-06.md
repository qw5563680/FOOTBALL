# FOOTBALL 需求交接｜竞彩二串一：一场单选＋一场双选

给 Claude Code 写任务单用。建议把100项指标的覆盖核对与采集列为 T44，把本玩法列为 T45。编号以项目实际安排为准。本单只要求形成候选、做纸面测算和复盘，继承项目“BET 禁用”。现有虚拟账户 D 的二串一应保留独立策略标识和账本，不得把两种成绩拼成一条历史。

## 1. 范围先固定

- 北京时间，限用户指定或最近一次完成研究的同一批比赛。只用竞彩足球普通胜平负，按主队视角和常规90分钟及补时结算。每组两场不同比赛，单选场只选胜／平／负中的一项，双选场只选其中两项。
- 默认展示3组，明确要求可增至5组。候选不足就给0–2组等实际数量。跨组不得重复比赛或球队。
- 单选是“这一场在票里只选一项”。两场要支持这次普通过关组合，未开单关并不妨碍合法过关。核对竞彩编号日、双方身份、开球、销售状态、过关资格、三项SP、报价更新时间、官方停售及可核实的实际出票截止，两场可执行时段必须重叠。
- 比赛已开始、结束、取消、停售、身份冲突或玩法不符，排除当前执行候选。销售资格或报价待核的只能单列参考。不得用海外赔率或让球玩法的价格冒充该玩法官方SP。

## 2. 单选场怎么挑

1. 复用这场已经冻结的赛前研究、胜平负完整概率、证据等级和模型版本，列明原研究唯一倾向。模型排名以球队模型为依据，市场赔率单独列。不得用球队名气、赔率最低、近期连胜直接选胆。
2. 按小梁对主候选的要求，单选项与有证据的原研究方向一致。若有可信独立模型概率，还须与其最高项一致。方向不明、关键反证未解决、第一第二在合理情景下容易掉换，就不要拿它当单选。原文允许解释方向差异；为便于第一版验收，建议这类仅进诊断日志，不进入主候选。
3. 该选项的竞彩SP小于1.20直接淘汰；等于1.20只通过价格下限。不能借双选腿拉高乘积来绕过，也不能把第二热门升为单选只为了过下限。
4. 不擅自规定单选胜率必须达到某个百分数。列清支持、反证和可能改变方向的条件。赔率和研究结论更新必须留版本。

## 3. 双选场怎么挑

1. 比较胜＋平、胜＋负、平＋负三种搭配，逐一写覆盖的两项、排除的第三项及其概率。两项必须属于同一场、同一普通胜平负、同一份概率分布。不得混用让球或境外“双重机会”报价。
2. 在其他资格均相同、按覆盖概率排序并采用两场独立近似时，概率前两项自然是该场覆盖最高的双选。必须说明第三项为什么被留下当风险；禁止固定“强队＋防平”、固定排除平局或为了高SP换掉概率更高的一项。
3. 若合理的阵容或赛程情景足以改变排除项，标为方向脆弱；未解决的组合只作参考。没有可靠完整概率，不报模型覆盖率。双选的两项不套单选SP 1.20下限。
4. 研究原来只判断一个结果。双选覆盖了另一个结果，赛后只算票面覆盖，不能补记原研究猜对。

## 4. 多组如何分散

- 同一轮给用户的所有主展示组中，每场比赛最多出现一次，每支球队最多出现一次。四支参赛队全部占用，包括作为对手、被选输球的球队。第1组用了国际米兰，第2组即使改为选国际米兰输或改用双选，仍算重复。
- 按统一比赛ID和球队ID核对，处理简称、译名、跨午夜编号。同一组的两条基础注共享比赛，是复式票本身；去重限制针对不同组。3组需要6场、12支不重复球队。
- 推荐实现默认：在同一证据等级枚举各场配对、谁单谁双和各选择，保留过滤前后范围。未经限制时N场有9×N×(N−1)种安排。按整组覆盖概率原精度降序，依次挑不撞球队和比赛的组；完全同分用稳定ID及选项顺序。每选出一组，登记该组全部四支球队，再继续检查后续候选。以保留最靠前的组为先，不为凑3组牺牲资格。不要把这种筛法说成对所有组的总命中率做了优化。
- 市场参考榜、实验榜、已验证球队模型榜分开。主展示以模型为先；如并列输出其他参考榜，说明只用于对照，不把跨榜重合组当新增分散机会。正式模型缺失时，不得拿市场概率冒充预测；按原规则，确有完整报价可以另列市场参考。
- 建议同批次重跑保留旧版、标明哪组替换、只认一个当前版本。已经计入纸面账的组锁定；同一决策批次重跑不能重复建票或绕开占用。不把“跨组不重球队”误写成某队整个赛季只能出现一次。

## 5. 排名、两注成本和盈利分别算

A单选α，B双选β、γ。展开为“Aα×Bβ”和“Aα×Bγ”两注。1倍、每注2元，整组成本4元。默认等额，两场都有效、正常结算时最多中一注。这个4元用于统一比较，无实际下单或资金授权。

- 有可用的联合模型时，记两条分支的联合概率q1、q2。只有单场概率时，明示“跨场独立近似”，q1=p(Aα)×p(Bβ)，q2=p(Aα)×p(Bγ)。
- 整组覆盖概率=q1+q2。按此排序。它是赛前估计值；赛后实际命中率用已结组数另算。
- 两条基础注各用各自的两个SP，分别算可核实规则下取位后的奖金，不能加成“一个组合赔率”。制作“第一注中、第二注中、都不中”三行，逐行写概率、整组本金、奖金、净收益。
- 整组盈利概率只加净收益严格大于零的分支概率；回本单列。若两分支奖金为G1、G2，无额外成本的税前示例中，EV金额=q1×G1+q2×G2−4，预计ROI=EV金额÷4。若成本、税费、规则有差异，用各分支实际净收益及概率核算；条件不明就标未核实。官方认定的无效场、取消等另走异常结算。
- 正常规则下，有的组合“中了其中一注仍亏”。如实展示。最终分别给覆盖最高组、盈利概率最高组、有没有可执行价值；未知就写未知。不直接把各组概率相加算“至少中一组”。

### 固定验收例（全部是假设数据）

A单选的模型概率60%、SP 1.25。B双选两项模型概率50%和30%，对应SP 1.44和3.20，第三项20%。假设两场独立、正常结算、每注2元，不计税费。

| 分支 | 概率 | 奖金 | 扣掉两注共4元后 |
|---|---:|---:|---:|
| 第一注中 | 30% | 3.60元 | −0.40元 |
| 第二注中 | 18% | 8.00元 | +4.00元 |
| 都不中 | 52% | 0元 | −4.00元 |

覆盖概率48%，盈利概率18%，税前EV为−1.48元，预计ROI为−37%。这个例子必须能测出“命中但亏损”。

## 6. 输出、冻结、复盘与验收

- 一张主表并列显示原单场研究判断、模型三项概率、市场参考、单选／双选、漏掉的结果、两注展开、三个SP和时间、组覆盖概率、整组盈利概率、EV、缺口及动作。附最容易同时击穿组合的条件。合格组为零就输出零。
- 区分历史门槛通过、前瞻已验证、实验概率、市场参考和纯定性。项目里的P2可用不能自动翻译成“已验证独立优势”。缺乏可以用于比较的同口径概率，不混榜、不拼两腿。
- 本期只开纸面比较和单独复盘，BET保持禁用。若未来项目正式允许实战，仍按原规则整批最多1组，并重新核实过关资格、共同销售窗口、两场四支球队的正式首发、独立概率证据、风险和保守净EV；首发公布晚于较早出票截止就不合格。只有临场能解决并能给出核对时间的具体问题才标WATCH，无法在时间窗口内解决的执行问题标PASS。
- 可评分的组必须在最早一场开赛前冻结；要宣称为当时可执行的组合，还要在两场共同的停售／出票窗口关闭前冻结并留下可复核的时间证据。保留原文、模型版本、未四舍五入的概率、数据与SP快照时间、筛选范围及分支现金流。后续报价、赛果和首发不能改写旧版。
- 赛后分开统计原单选判断命中率、两条基础注各自结果、已结合规组的实际覆盖率、整组盈利率、纸面投入／盈亏／ROI。将异常、待结、事后重建分别标注；未出票不计实投业绩。
- 除了示例，再验收这些边界：单选SP 1.19排除、1.20继续审计；双选含低于1.20的选项不因此剔除；仅不支持单关而支持2串1可入过关审核；球队换简称仍能去重；候选不够允许空；截止前缺首发不可能转BET；重跑不重复记账；纯市场输入只能出市场参考。
