# T34 · 冻结前瞻预测、新旧并行比较与采用决定（阶段 E）

## 前置依赖
T33 至少一个候选在离线评估中不劣于基线且无泄漏疑点；T17 / T19 / T25 现有冻结与记分板链路。

## 范围
1. 每日预测并行输出基线与实验模型（`model_name` 区分，`p2_label` 实验模型固定「P2 实验」，不下注，T28 规则不变）；冻结赛前输入快照（特征值、所用统计场数 n/N、`availability_basis`、阵容是否赛前捕获）与模型版本、生成时间。
2. 记分板 / 摘要：按模型分列指标；每场显示概率、最高项、前两项差值、模型名、两队实际用到的历史场数、进入本场计算的技术字段、重要缺失与回退；完整报告附双方近 10 场逐场数据与主客场汇总（带 n/N，缺字段比赛保留）；比分展示为实际计算的最可能比分及概率。
3. 采用决定规则（事先写死）：前瞻共同样本 n ≥ 预设（按联赛 ≥ 200）、LogLoss 配对差 < 0 且自助 95% 区间上限 < 0、校准不劣、覆盖率不降；满足后由所有者决定是否把候选设为正式模型；否则保持「实验未验证」。
4. 文档：README 每日结果说明；ARCHITECTURE 并行模型与冻结输入；审查记录归档。

## 不做
- 不降低 P2 门槛；不改旧评价口径；不启用 BET；不删除难预测比赛；不以展示代替验证。

## 测试（离线）
并行模型冻结格式、输入快照字节固定、摘要字段、采用规则判定（满足 / 不满足两种）、P2 实验不下注。

## 真实验收（审查者）
连续 ≥ 14 天定时运行两模型并行；比较报告由冻结记录重算，与每日摘要一致。

## 完成标准
pytest / ruff 通过；采用与否的决定与证据写进审查记录。
