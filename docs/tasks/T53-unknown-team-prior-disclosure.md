# T53 未知球队默认实力须在日报标明并移出主候选

来源：2026-11-12 独立复核（ChatGPT）发现、Claude 复现。排在 T52 之后。

## 现象与证据

- `src/zucai/predict/dixon_coles.py` 对训练集外球队使用 `weakest_quartile_half_shrinkage` 先验，
  预测原件记录 `metadata.unknown_team_prior = true`，但日报 Markdown、14 场/任九报告和二串一筛选均未使用该标记。
- 实例 AC米兰–费伦茨（`forecasts/2026-11-06/42024862563-1/forecast.json`）：冻结主胜 96.29%；
  同一模型（`models/42024862563-1/欧战.pkl`）把先验换成训练集均值后为 86.25%，相差 10.04 个百分点，平局 3.07% → 10.02%。
- 2026-11 冻结预测 478 条中 4 条使用该先验，其中 3 条最高项在 87%–96%。

## 范围

- 单场、14 场、任九、二串一中标明哪一方使用默认实力及先验方法。
- 这类比赛保留研究概率，但不进入二串一主候选、任九模型单选与任何「最看好」排序；诊断区列出原因。
- 记分板/复盘按是否使用默认实力分层展示。

## 不做

不改先验公式与模型参数（如需调整另开提案）；不回写已冻结预测与旧账本；不引入赔率参与判定。

## 验收

1. 历史比赛 `jc:2042523`、双方均已知、双方均未知三种情形：缺失方标注正确。
2. 含默认实力的比赛不出现在主候选；双方已知比赛的概率与候选资格与修复前完全一致。
3. 历史预测与旧账本文件 SHA256 不变；全量 pytest、ruff 通过。
