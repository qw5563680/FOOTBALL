# T07 · 14 场胜负彩期次支持

## 目标
抓取当期与历史 14 场胜负彩期次，映射到 `matches`，输出每期 14 场的胜平负概率表和按置信度排序的复式建议。

## 范围
1. `src/zucai/sources/c500.py` 增加 `C500Sfc(Source)`：解析 `trade.500.com/sfc/`（需验证），得到期号、截止时间、14 场对阵。
2. 队名与开赛时间对齐到已有 `matches`，对不上的比赛新建 `source=c500` 记录并记录未匹配情况。
3. `zucai fetch sfc [--issue 期号]`，`zucai report sfc [--issue]`：
   - 14 行表：序号、对阵、胜/平/负概率、最可能结果；
   - 复式建议：给定总注数上限（默认 64 注），按概率选择单选/双选/三选组合，输出注数和覆盖的总概率。
4. 测试：样本解析、对齐逻辑、复式注数计算。

## 不做
- 不做任九的单独优化，先沿用 14 场结果表。

## 验收标准
- 真实抓一期并生成报告，贴进 PR。
