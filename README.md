# FOOTBALL 云端赛程、SP 与赛果

[打开按北京时间分月的比赛表](matches/) 可查看球队、开球时间、状态、90分钟比分、半场比分，以及开赛前最后一次采集到的完整普通胜平负 SP。缺失值留空。比赛 ID 与代码项目保持一致，竞彩编号要连同日期使用。

所有采集时点的五种玩法报价放在 [state/odds](state/odds/)，按采集时间的 UTC 月份分文件。[数据清单](feed_manifest.json) 列出每张表的字段顺序、行数和 SHA-256 校验值。同一场有多个市场观察时点，恢复时会核对文件和数据库一致性。

`finished` 表示已有确认赛果，`cancelled` 包含官方认定无效的场次。`scheduled` 表示数据库正在等确认赛果，比赛可能尚未开赛、进行中或等待开奖。当某场没有同一时刻的完整赛前普通胜平负报价，月表的 HAD 三项留空。

首次存档收录 2026-09-02 至 2026-10-31 的官方赛果和 11 月 1 日晚的一次赛前采集。回填历史比分使用本次实际采集时刻，不能用这个时刻冒充当年赛前已知。此数据分支记录赛事事实、报价和已开奖比分。另行冻结的模型概率和研究报告见[11 月 1 日赛前研究目录](https://github.com/qw5563680/FOOTBALL/tree/codex/prematch-20261101/reports/2026-11-01-prematch)。

2026-11-01 北京时间 21:27 的增量验收在可访问官方接口的环境完成，并上传到此私有分支。共 866 场（已开奖 833、取消或无效 6、等待确认 27），保存 2,319 项赛前报价。这是一次实际同步的归档，持续定时采集尚未启用。
