# T61 catalogue offline fixtures

All `catalogue-*-synthetic.json` files are fabricated offline test inputs, not live catalogue evidence or permission observations. Names deliberately say Synthetic. IDs resemble provider identifier formats only. The fixtures do not establish account access, current catalogue completeness, historical coverage, or source approval.

API-Football seasons mirror the metadata shape in the pre-existing T30 offline fixture: nested `coverage.fixtures` flags describe technical detail availability and do not prove schedule/results entitlement. football-data.org's season count is deliberately much larger than its one actual current season to catch invented historical ranges. Error fixtures use non-secret synthetic credential placeholders and include escaped/shadowed echoes.
