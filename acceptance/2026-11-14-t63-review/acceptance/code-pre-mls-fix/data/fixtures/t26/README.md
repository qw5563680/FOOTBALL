用于验证 14 场全部结束、单选命中和复式覆盖；绝非这些真实球队的实测结果。
预测测试复用 T07 的合成球队概率，所有模型占位字节只写测试临时目录，绝不加载。
采集测试全部拦截 HTTP，不请求真实源站。

full-bridge.html 是为覆盖完整14场而构造的离线桥接页，不是实抓响应。复用 T07 对阵、球队 ID 与
已有对照；T07 对照页未覆盖的场次使用 900000+序号 的虚构体彩 ID 和测试队名，禁止用于生产身份配置。
