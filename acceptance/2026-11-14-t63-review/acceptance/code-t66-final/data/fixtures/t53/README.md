## 实跑方法

普通回归只使用本目录原件，不载入二进制模型或请求网络：

```bash

```

完整验收需要先将上述不可变提交解压到独立目录，在仓库中执行：

```bash
PYTHONPATH=src python scripts/verify-t53-archive.py \
  --archive /path/to/extracted-1b8cc9c \
  --output /path/to/new-t53-evidence
```

输出目录必须不存在且与输入档案分离。脚本会：

1. 核对固定原件及 `models/42024862563-1/欧战.pkl` 的 SHA256，再加载原模型。
2. 实算主队未知、客队未知、双方已知三条真实输入；同环境基线代码与新版代码的概率
   按同规范 JSON 字节比较，三条全部一致。已知队与原冻结值也完全一致；两条未知队
   重算与旧冻结值有基线本就存在的约 `1e-16` 浮点差，摘要逐项保留，不用容差掩盖。
   展示和筛选始终使用原冻结值，不用重算值替换。两个明确合成的未知名称用同一原模型运行，
   验证双方缺失标记。
3. 将本地基线 `eb335c7` 的完整 `src/` 导出，另起解释器执行旧代码，避免用新代码自比。
   对同一组合准入控制比较六场已知队资格、概率及三个选组，再只添加真实默认实力元信息验证排除。
4. 从完整原档案恢复临时库，在同一冻结批次上分别执行基线和新版 26159 报告构建。
   验证研究概率不变、原有已知队排序不变、默认实力比赛退出置信排序；
   任选九的合成发布状态只验证筛选，不声称报告在历史赛前发布。
