# T20 离线样本

`fdorg_cl_2023.json`、`fdorg_cl_2024.json` 与 `apif_3_2024.json`、`apif_848_2024.json`
是 2026-11-02 UTC 实测响应的裁剪件，每份至多五场，覆盖加时/点球的常规时间比分。
`apif_plan_2026.json` 是当季整季权限拒绝。来源 URL、原始 UTC、原件和裁剪件 SHA256
见 `provenance.json`；所有样本导出前后检查凭据回显，不含请求头或 key。

裁剪件为测试专用，不是完整赛程证据，不能据此发布生产别名。
`identity.json` 为明确合成的身份图样本，中文规范名不是正式别名配置。
测试可调整这些离线样本的日期、ID、参数、比分或分页模拟异常；所有 HTTP 由 responses 拦截，
不使用真实凭据，不发出真实网络请求。
