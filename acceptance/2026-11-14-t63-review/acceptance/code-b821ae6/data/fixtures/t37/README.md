# T37 离线复现与参数来源

- `synthetic.json`：60 场虚构 A/B/C/D 比赛，随机种子 1 的极端攻防样本；包含合成比分与一次拟合参数快照。
  测试重新拟合该合成历史，B 主场对 C 时负 rho 使旧实现抛错。不是实际赛果。
- `boundary.json`：随机种子 37 生成的第 5 组虚构攻防参数，rho 在理论上界时底层运算出现微小负值，验证舍入修正也有记录。
- `parameters.json`：只摘录 T33 三个训练折的基线参数、已有平局校准截距、截点与训练数量，以及四场身份/时间/原报错。
  **没有这四场的赛果，也没有训练赛果**；另有五组虚构常规配对用于验证原矩阵逐值不变。
  来源是数据分支提交 `4bae61d` 下 `experiments/t33/2026-11-05-round1/initial/` 的两个 folds 文件，
  文件名和 SHA256 写在 fixture 的 `sources` 中，已与该提交的文件及 SHA256SUMS 核对。

这里使用的是 **Codex 已发布的 T33 参数**。Claude 在 PR #64 及 T33 审查记录中独立确认相同四场失败，
但其独立复算的 folds 文件未在可访问的归档或评论中提供。本 fixture 不冒称来自那份独立文件；
包含任务要求的 2025-09-07 参数折，审查者可再补独立版本作交叉回归。

penaltyblog 1.13.1 的公开 `fit` 仅接收优化选项/梯度开关，rho 边界固定为 [-2.5, 2.5]，
没有接收逐对阵非负约束的公开参数；因此不保证未来配对的四个修正因子合法。
前三个法甲案例正 rho 超上界；法乙案例负 rho 低于下界，使 `1 + μ*rho` 为负，
**不是边界舍入，也不是先验产生负值**。法乙负格绝对值小于依赖的 1e-9 容差，依赖先放行，
随后项目的严格非负检查拒绝；法甲三场直接被依赖拒绝。

选择 A 可以只处理本场，无需改变拟合、先验或校准。合法区间内的正常对阵使用原路径；
越界对阵只改本次计算的 rho，原模型参数与训练内校准行选择不变。
法乙的客队强度仍极端，0–9 网格几乎丢弃全部质量；本任务不调整强度与网格截断，
`excluded_score_mass` 继续披露这一限制。修复无效概率不等于预测准确性得到验证。
