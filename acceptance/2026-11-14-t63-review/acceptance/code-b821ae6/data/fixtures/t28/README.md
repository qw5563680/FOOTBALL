# T28 离线合成样本

沿用 `../t19/forecasts.json` 晚批次的比赛、概率和完整冻结 SP，以及 `results.csv` 的赛果。
`p2-gate.json` 只提供冻结行的 P2 状态变体：严格布尔 true、false、字段缺失、null 和非布尔真值；
同联赛、同版本与原文字标签不会替代冻结行的布尔字段。全部为测试数据，没有真实请求。

`legacy-experimental-ledger.jsonl` 用修改前 main `42e9add` 的 `advance_ledger`，
对晚批次 `jc:one`（`p2_ready=false`）在 `2026-11-01T10:00:00Z` 生成后原样保存。
它模拟旧规则已开的实验票，运行测试时不再生成基线。三档各有 A/B/C 注额 100/200/100，
冻结主胜 SP=2.5；D/E 候选不足，没有注单。赛果主胜后各档返还应为 250/500/250，
资金应为 10150/10300/10150；决定时刻的可用现金仍为 9900/9800/9900。
测试保留原决定字段与指纹，只允许按既有规则补结算，再次运行字节不变。
