`unsettled-2026-11-17.json` 裁自数据归档 `3d9740f` 的真实页面：
保留原 `matchResult[0:3]`，包括两条未结算记录和一条已结算记录；行内容不变。
只保留匹配的赛事字典，分页总数改为裁剪后的 3。原来源、原 SHA256、真实捕获时间见 `unsettled-provenance.json`。
测试对成功重取响应的结算状态和比分修改仅作合成变体，不声称它是真实结算结果。
