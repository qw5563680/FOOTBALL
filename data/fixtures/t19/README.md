# T19 离线合成样本

`forecasts.json` 为手工规则生成的三批 T06 schema 2 预测（开球前两批、开球后一批），
`results.csv` 为合成常规时间赛果。全部比赛、概率、SP 和时间均为测试数据，无真实请求。
包含同场更新、无 SP、生成时已知结果、晚到结果、assumed 和无结果；测试通过真实
T06 导出、SQLite 与归档恢复流程读取它们。预期数值直接按样本计算，不运行模型生成答案。

有 SP 的场次固定使用主/平/客 `2.5 / 3.0 / 3.5`；晚批次前三场的主胜概率分别为
`0.48 / 0.46 / 0.43`，因此最大 `ratio = p × SP` 为 `1.20 / 1.15 / 1.075`。
1.05 档三场入选，1.10 档只入选前两场。比分矩阵、比分列表与 SP 去水概率同步保持一致。

`thresholds.json` 是三档严格比较的边界样本：恰好 `1.00 / 1.05 / 1.10` 不入选对应档，
`1.001 / 1.051 / 1.101` 入选对应档；另含低于 1.00、48% × 2.5 = 1.20 和最大 ratio 并列用例。
边界测试同时检查 A/B/D/E 四个模型账户与不受门槛影响的 C 对照账户。
