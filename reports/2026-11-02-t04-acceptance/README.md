## 复核和使用限制

实际核对了Parquet往返、两份文件哈希和逐窗证据：所用历史开球与available_utc都严格早于
各目标截点，所用报价也严格早于截点。仓库测试将继续检查这些冻结文件在Windows/Linux检出后未变。
输入只读，文件排他创建；再次导出请使用新文件名。代码不会自动覆盖或上传日常新结果。
独立审查后，公共Python API补齐事务快照和ORM缓存刷新；最终函数在同一as_of下重读原副本，
复现全部866行和证据，仅计算完成时间不同。原冻结文件未覆盖。最终全套150项测试通过。

取模型矩阵时只使用`MODEL_FEATURE_COLUMNS`白名单；market和meta列独立保存。当前Dixon–Coles不消费此表。
还需要更完整、时间依据可靠的历史数据，事先确定缺失处理和时间切分，再训练及样本外验证新的特征模型。
