- `src/zucai/sources/cup_identity.py`：只有缺少独立生效旧授权的范围条目才阻止旧杯赛桥。

  不再由新赛事名称的字典序决定旧条目能否传播；只有范围条目时仍不能擅自激活其他赛事。
- `tests/test_t68_scope_coexistence.py`：28个并存与拒绝案例，覆盖两项杯赛、桥接/数据库/图推断路径、
  目标杯赛/其他赛事追加、三种赛事字典序、旧传播证据、输入顺序、不生效状态和冲突。
