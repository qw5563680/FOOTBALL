## 实际训练与周滚动回测

两组使用同一数据库、英超、90天半衰期、回测区间2026-09-01至2026-11-01T17:00:00Z；按周训练，严格要求历史开球和结果可知时刻早于周截点。运行发生在结果已被查看后的开发阶段，是历史回放，不是前瞻未见测试。没有参数调优、重新模拟或10万次抽样。

|---|---:|---|---:|---:|---:|---:|---:|
|jc|61|{'jc': 61}|0.00%|0|不可计算|不可计算|0|
|fd,jc|1981|{'fd': 1920, 'jc': 61}|96.92%|61|1.296154|0.722030|0|

同一61场的固定等概率参照（主/平/客各1/3）为Log Loss 1.098612、Brier 0.666667，
见[uniform_baseline.json](uniform_baseline.json)。本次模型两项误差都高于该参照，不能作为启用模型的依据。
这是固定数学基线，不是市场概率。周滚动各折实际训练100%依赖FD的assumed可知时间；表中的96.92%是最终保存模型的比例。

指标保留原精度于[train_jc.json](train_jc.json)和[train_jc_fd.json](train_jc_fd.json)，包括逐周训练样本、assumed_training_share、assumed_eval_share、跳过原因和校准分箱。原jc赛果均在11月1日才实际采集，早期周截点可用训练不足；不得把回测n=0解释为0损失，也不能宣称联合模型已证明优于仅jc模型。FD新历史明确假定开球后三小时可知；当前季官方重叠保留原jc captured时间，没有为了回测覆盖率改成assumed。

`closing_odds`不读取到模型、回测或正式市场基准；模型输入仍只有球队、常规时间进球与时间衰减。有时间戳的赛前had报价不足时市场比较为空；本次不能证明独立投注优势。

实际CLI参数（工作目录和临时路径以占位符表示）：

```bash
zucai fetch fd --div E0 --season 2122 --assume-known-after 3h --db <副本.db> --raw-file <E0-2122.csv>
zucai train --league 英超 --source jc --db <副本.db> --since 2026-09-01 --as-of 2026-11-01T17:00:00Z --output <临时jc.pkl>
zucai train --league 英超 --source jc,fd --db <副本.db> --since 2026-09-01 --as-of 2026-11-01T17:00:00Z --output <临时jc_fd.pkl>
python examples/t08_verify_identity.py --db <原jc库> --index <current_index.json> --config data/football_data_co_uk/candidates.json --year 2026 --output <新证据目录>
```

其余59文件使用同一fetch_fd入口离线重放并导入。CLI首文件先入库380场，再回放为unchanged；汇总新增数直接查询最终数据库，不重复累计这380场。初次运行发现跨联赛已知别名被旧英文身份误阻止，修复后只重放被拒绝的具体行；[retry_summary.json](retry_summary.json)保留重放量，原失败详情仍在临时运行目录。只在其他联赛存在的英文历史保持原身份，不借当前联赛批准映射去合并；同一联赛后续批准仍须先核对存量。

## 完整性和限制

最终库计数：`{'matches': 28508, 'results': 28475, 'odds': 3450, 'closing_odds': 99805, 'predictions': 12, 'teams': 632}`。原赛果、赔率、预测、官方比赛身份字段及已占用counterpart均保持；没有已知规范身份的jc/fd重复，外键检查通过。详见[integrity.json](integrity.json)。仅补空counterpart及已核验Team.aliases。

[source_manifest.json](source_manifest.json)列61个输入原件的URL、读取UTC和SHA。最初16个sidecar尚未含SHA，后按已记录字节校验并另建回放副本，保留原采集时间；不声称SHA当时已经落盘。早期下载的自动重定向未单独限速，已改成逐跳限速，实际复抓两跳间隔2.0秒且哈希一致，见[redirect_smoke.json](redirect_smoke.json)。

[final_rejected_rows.json](final_rejected_rows.json)、[suspected_duplicates.json](suspected_duplicates.json)、[unmatched_names.json](unmatched_names.json)分别保存拒绝、潜在重复与未对齐历史名，不把这些行补为0分或任意开球时间。样本存在升降级与未知历史球队，不代表所有赛事均有相同覆盖。

代码与样例可运行不等于预测准确；当前没有前瞻验证和相对同时间市场的优势证据，仍禁用BET。
