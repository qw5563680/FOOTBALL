# T33 首轮技术强度实验

非购买建议 · BET 禁用

本批只研究近期射正/xG强度DC回归与去掉对手against项的消融；系数由训练折拟合，候选二延期。
不替换正式模型，不改params/P2/T28。历史回放不是新增未见验证。

## 先冻结的协议与输入

- 协议先行提交：`4e931c0`；同样本/六组配对澄清提交：`37d0ad6`，均早于任何真实结果。
- 射正与初始诊断输入：数据分支`bcf1430`；库SHA256：`066ab44454fd193062556ff4973d9d7519afc5ced2093fdb811e51c47151c5fc`。
- 最终xG输入：数据分支`da17cbc`；库SHA256：`83944b6cd812d7c52f1db31b1d4c6c7b6f80eb3da6f5f7edc85ab7608d813c22`。
- 实验代码提交：`a747b08066afa1c172b81d139b580cdee1f94d98`；源文件逐个哈希和依赖版本见 input_manifest.json。
- 协议SHA256：`491173e2bf24dedbe8064ca79fea892056735e72dfbcb64b8c8ad2d6af9c35bc`。
- 训练起点2021-07-01；2024/25月度选5/10场窗口；2025/26每周重拟合，7月换季，固定90天半衰期。
- 基线为原样DixonColes实现、T15未知队先验与训练折平局偏移；不是线上后来调参配置的精确回放。
- full/ablation训练ID、四项完整性掩码、回退行相同；消融只去掉against系数。
- strict排除所有回填行；backfill_replay只假设历史开球+3小时可用，真实抓取在赛后很久，可能含后来更正。
- 每个训练样本在自身开球截点算特征；本场/未来场/未来captured更正不进入窗口；null不填0。
- 市场只读明确counterpart、同身份且截点前jc had；预测和选窗结束后才加入对照；不使用fd收盘价。
- LL/Brier越低越好；首项并列按均分期望计分。比分Brier为0..9网格加“其他”，复用现行截尾归一化；不证明比分尾部校准。
- 配对按UTC周整块重采样2000次、seed3301，95%百分位区间；同场配对不拆开，跨联赛同周一起抽。
- 评价期是历史开发资料，不冒充新盲测；没有真实实验的回退差值0不表示技术模型等效。

## 输入覆盖与限制

fd表使用bcf1430快照，xG最终表使用补回填后的da17cbc；两个快照的teams/matches/results/odds文件字节相同。补回填只扩展apif技术统计，fd既有实验无需重拟合。
xG有效统计覆盖（2024/2025供应商季）：英超379/380、380/380；西甲379/380、379/380；意甲377/380、379/380（2024另有2个球队xG空值）；德甲303/306、306/306。缺场/空值仍触发窗口缺失和回退，不称100%覆盖。
欧战统计不足，明确未覆盖；不拟合或转用国内模型冒充杯赛实验。
当日可知的技术快照不足，strict栏技术实验n=0，不能据历史回放启用P2或BET。

基线四场未生成：fd:F2:20250823:boulogne:st-etienne；fd:F1:20250912:marseille:lorient；fd:F1:20250914:brest:paris-fc；fd:F1:20251003:paris-fc:lorient。均为原模型比分矩阵无效（含负值），按现行实现保留失败，未改旧模型。fd全目标3221，基线n3217，候选n3218；配对结论以六列共同成功样本3067为准，不能用不同n硬比较。
真正实验n指该列样本中技术候选实际运行的数量；基线/均匀列只是对照，不因此成为技术模型。
