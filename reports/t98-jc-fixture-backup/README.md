# T98 竞彩备用名单离线验收

本次以已归档的 500 网根页运行离线用例。原件 SHA-256
`fa54a13f667aedd35044b3e03ab3c34ab54323e3fb135331f47d0a9654ba4ef5`。
回放时刻、库内身份和后到官方响应是测试控制输入。[根页原件](../../data/fixtures/c500_root_20261102.html)

| 验收情形 | 离线结果 |
| --- | --- |
| 官方成功，名单齐全 | 无现成根页时增加 0 次请求。有现成根页时只复用原件，库字节相同，未写入备用状态。既有日报黄金样本逐字节一致 |
| 官方成功，少一个编号 | 复用同班原件，只补 `jc:2042439`，请求仍 1 次。官方已用同一销售日及竞彩编号时，原名单保留 |
| 官方失败 | 根页有 9 条未停售行。种子库只准入意甲 `jc:2042439`，归档保留响应哈希和 UTC 读取时刻，恢复后原证明相同 |
| 无法核实 | 法乙客队「南锡」和编号 1130 有明确缺口；另测未核实赛事和午夜占位。均没有新建球队或比赛 |
| 报价及预测 | 备用采集后赔率表 0 条。离线冻结对跨午夜场次生成球队预测，市场参考和融合均写明缺少官方报价。即使种子库保留早期报价，也不会使用 |
| 官方恢复 | 相同体彩 ID 替换主队、开球时间、竞彩编号和销售状态。官方先报停售但缺主队时暂停备用预测，保留身份凭据以接收后续正式更正。比赛及球队总数不增加，原冻结文件字节一致 |
| 账户及纸面串关 | 备用批次不入虚拟账户 A–E 或串关 F；新官方批次沿用原规则。旧批次保持原资格 |
