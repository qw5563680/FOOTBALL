# T72 球队＋市场融合离线验收

## 已验证

| 检查 | 离线结果 |
| --- | --- |
| 球队模型隔离 | 相同采集副本、参数和截点跑完开关两版。训练行数、模型文件、球队概率、比分矩阵及原预测字段一致 |
| 融合生成与证据 | 对数线性概率合计为 1，两个端点各自等于原输入；缺球队模型、缺报价、迟于截点、只有收盘价或非法协议均只影响融合 |
| 归档与日报 | 概率、真实截点、市场快照编号、采集时间及权重证据可重读；第三栏仅显示 T72 模型，逐批统计首选方向变化 |
| 独立评分与账本 | 相同冻结归档中，带与不带融合计分的两份非空账本逐字节一致；融合评分可由同一比赛 ID 上三组冻结概率复算；重跑增量为零 |
| 前瞻规则 | 测试覆盖 200 场结论和复估门槛、新版生效前仍用旧版、300 场两项关停条件、独立收盘价对照及时间和哈希不足时的保护 |

比分、收盘价和融合结果不进入球队模型。旧手动线性融合入口和既有技术实验的保护规则保留。
测试使用临时归档和合成数据，成绩用于核对逻辑。测试中的已选权重不进入生产配置。
