## 实际命令

以下路径改写为相对隔离验收目录；命令参数/输入与实际运行一致。`data/zucai.db`为T06验收库的SQLite备份副本。

```bash
python -m zucai.cli fetch sfc --issue 26155 --db data/zucai.db --matches-out inputs/26155.csv
python -m zucai.cli report sfc --issue 26155 --db data/zucai.db --batch reports/2026-11-01-t06-acceptance/live-batch-v2/forecast.json --out issue26155
python -m zucai.cli fetch sfc --issue 26156 --db data/zucai.db --matches-out inputs/26156.csv
python -m zucai.cli predict --db data/zucai.db --matches inputs/26156.csv --model-file models/bundesliga.pkl --model-file models/epl.pkl --model-file models/la-liga.pkl --model-file models/serie-a.pkl --out forecast26156
python -m zucai.cli report sfc --issue 26156 --db data/zucai.db --batch forecast26156/forecast.json --out issue26156
```

实际调用通过`zucai.cli.main(argv)`执行以上CLI参数。模型与数据库文件不提交；模型SHA、训练范围、
数据可知时间与所有排除原因都在冻结JSON内。第三方原始响应保留在临时RawStore，摘要及SHA进入报告。
