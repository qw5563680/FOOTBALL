## 方法与范围

- 全池共同攻防尺度、一个主场参数和低比分修正；无 Elo、联赛系数、新依赖、首发或赔率特征。未知球队仍用 T15 最弱四分位、向全池均值收缩 50% 的先验。
- 新多联赛求解路径为 `pooled_dc_full_gradient_al_slsqp_v1`：同一 penaltyblog 1.13.1 DC loss、bounds、attack 和约束、最终 SLSQP 精度；补齐完整似然梯度，以同折 AL/L-BFGS-B 求初值，最终仍由原目标的 SLSQP 验收。原依赖低比分项梯度不完整，新旧数值不承诺相等。国内与单联赛 pooled 严格保留原 `engine.fit()`。
- 完整梯度与 loss 的离线有限差分及独立随机检查通过；初始化不会直接作为最终模型，非有限值、越界、attack 和残差超过 1e-6 或最终求解失败均拒绝。求解方法及诊断冻结保存，并绑定 P2 证据。
- 半衰期网格 90/180/270/365/540/730 天。统一 UTC 7 月换季，S 季 monthly 只按模型 LL 选择且候选须完整同样本；同分取较短值。S+1 独立验证，P2 用 weekly 重评，跨季周拆开。
- 平局校准开关仅用所选 S 候选的 draw_bias：绝对值 >3pp 才在 S+1 开启。训练仅有截点前可知赛果；赔率不进入先验、校准或候选排序。
- 2223/2324 没有前季选参映射，明确使用 90 天、校准关闭的历史回落；不得把今天推荐值倒投到选择季。最新两完整季2425/2526分别用2324/2425的选择。2627是部分季。
- 任务单原列欧罗巴/欧协联2223–2425；当前付费快照另有2526，因此也报告2526，以满足“最新两完整季”的验收。欧冠2223没有数据，不补造。
- 三列为同一模型评分样本的 model / uniform / jc market；LL / 三分类求和 Brier 越低越好。市场为 jc 严格赛前最后完整 had 去水，缺失为 null，另给同场模型。市场更接近开球时点，不能声称与周初模型等信息。
- 默认训练联赛范围在本次截点按已有球队 ID 的参赛关系确定，历史各折使用该固定范围；未逐折恢复当时的参赛范围或身份版本。范围中的赛果仍须严格早于各折可知截点。
