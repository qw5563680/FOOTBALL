## 批准到合并的离线演练

两项赛事各做一遍，使用测试生成的球队编号和审批文件。原队名及审批清单的正式文件未被修改。

- 无官方开球时刻时，四项待建身份结论均为待核。补入归档时刻后，给出两项新建、两项关联既有身份。独立的证据回归覆盖缺精确时刻、窗口内多个候选和主客方向冲突。
- 经真实命令入口读取测试审批清单，每项赛事创建两支规范身份、关联两支既有身份。再以测试中的带范围获批别名合并，一场比赛的两支临时球队同时改指规范身份。样本没有可关联的库内竞彩同场记录，新增关联 0 条。第二次合并移动 0 场、建立 0 条关联。
- 合并前后均为 5 场比赛、5 条赛果，比分、可知时间和比赛编号一致。旧的不带范围别名在原入口另行合并一场，再跑为 0。
